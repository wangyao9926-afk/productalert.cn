# 官网新品情报监控系统

一个面向品牌、选品、运营和竞品研究人员的官网新品情报监控系统。

它不是单纯的网页变化提醒器，而是围绕“发现新品、理解新品、沉淀情报、及时通知”设计的工作台。

## 产品定位

输入品牌官网或指定页面后，系统会持续监控公开页面、sitemap、RSS、产品列表页、新闻发布页和可配置页面区域。当发现疑似新品或重要变化时，系统会提取结构化信息，生成情报摘要，并按规则通知相关人员。

## 四个核心模块

1. 新品监控
   - 自动发现官网里的产品页、新品页、新闻页、发布页
   - 支持手动指定新品列表页和详情页规则
   - 支持首次扫描建基线，避免历史商品误报
   - 支持关键词、排除词、品类和品牌规则

2. 页面变化监控
   - 支持整页、区域、元素、文本和视觉变化监控
   - 保存变化前后快照
   - 记录变化发生时间、变化范围和变化内容
   - 适合价格、库存、文案、活动、页面结构变化监控

3. AI 新品情报分析
   - 判断变化是否真的代表新品发布
   - 提取产品名、价格、图片、发布时间、规格参数、功能卖点
   - 生成一句话简报、核心卖点、适用人群和竞品观察
   - 标注置信度，重要信息可进入人工复核

4. 通知与工作台
   - 支持企业微信、飞书、钉钉、邮件、Telegram、Webhook
   - 支持按品牌、关键词、品类、重要程度路由通知
   - 提供新品时间线、竞品库、搜索筛选、状态标记和导出
   - 让监控结果进入可管理、可追踪、可复用的情报流程

## 当前版本

当前代码是第一阶段本地原型，已经具备：

- 添加品牌档案
- 为每个品牌配置多个监控源
- 支持官网首页、sitemap、RSS、产品列表页、新闻页和自定义页面
- 自动读取 `sitemap.xml`、RSS 和页面链接
- 首次扫描建立基线，避免历史页面误报为新品
- 检测新增疑似产品/新品页面
- 提取标题、描述、图片、价格和功能卖点
- 支持 CSS selector 限定监控区域
- 保存监控源文本快照和页面变化事件
- 高亮展示新增/删除文本片段
- 支持新品和变化事件的收件箱状态
- SQLite 本地保存记录
- 保存扫描日志和失败原因
- 支持通用 Webhook 通知
- 支持手动检查品牌或单个监控源

## 启动

如果当前目录已经有 `.venv`，可以直接运行：

```powershell
.\start.ps1
```

或手动启动：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

打开：

```text
http://127.0.0.1:8000
```
